# 변경 내역

## 1.2.1

### 개선
- **백그라운드 서비스**: Poweramp를 여는 것만으로는 시작하지 않고 곡이 실제로 재생될 때만 시작하며, 더 이상 재생되는 것이 없으면(일시정지 제한 시간 후) 스스로 종료
- **커버 업로드**: "cover.jpg" 대신 무작위 파일 이름 사용 – x0.at이 업로드를 거부하기 시작했기 때문

## 1.2.0

### 새 기능
- **Discord 계정 연결**(*상태* 탭): 실시간 미리보기와 *상태* 탭에 실제 이름과 프로필 사진이 표시됩니다
  – 공개 프로필만 보관합니다
- **26개 언어 추가**: 프랑스어, 스페인어, 포르투갈어(브라질), 이탈리아어, 네덜란드어, 덴마크어, 스웨덴어, 노르웨이어, 핀란드어,
  폴란드어, 체코어, 헝가리어, 루마니아어, 그리스어, 튀르키예어, 세르비아어, 아랍어, 힌디어, 인도네시아어, 베트남어, 태국어, 중국어,
  일본어, 한국어(AI 번역 – 수정 제안 환영)
- *앱 설정*에 **언어 선택** 추가(Android 13 이상에서는 Android의 앱 설정에서도 가능)

### 개선
- 배터리 절약: 휴대전화가 절전 상태여도 “일시정지됨”이 제때 사라집니다. 프레즌스가 꺼져 있거나 Discord가
  없으면 기기를 깨우지 않으며, 재연결 간격이 점차 늘어납니다
- 네트워크와 메모리 절약: 커버를 다시 확인하는 빈도가 줄고, 찾지 못한 앨범은 12시간 동안 다시 검색하지 않으며,
  앱이 백그라운드에 있으면 이미지를 메모리에서 해제합니다
- 수정: 가져온 설정이 올바르게 보정되며, 작업 관리자에서 중지한 후에도 재생하면 프레즌스가 다시 표시됩니다

## 1.1.0

### 새 기능
- 점 3개 메뉴에 **앱 설정** 추가: *시스템 설정 따르기* / *라이트* / *다크* 테마, 다크 모드용 **AMOLED 블랙**,
  **Material You** 색상(Android 12 이상)
- **정보**: 제작자의 GitHub 프로필 사진과 가운데 정렬된 링크
- **번갈아 표시되는 텍스트**: `%artist% || %title%`는 아티스트와 제목을 번갈아 표시합니다(*표시* 탭의
  *전환 간격*, 5–60초)
- Poweramp 스타일의 **새 앱 아이콘**: 이퀄라이저 막대가 있는 말풍선(Android 13 이상 테마 아이콘도 지원).
  앱 내 로고, 스플래시 화면, Discord 이미지도 이에 맞췄습니다

### 더 매끄러워짐
- 최적화된 빌드(R8 + 기준 프로필): 화면과 탭 전환이 더 이상 끊기지 않습니다
- 설정, Poweramp 상태, 이미지를 백그라운드에서 불러옵니다
- 실시간 미리보기는 재생 위치만 1초마다 업데이트합니다. 멀리 있는 탭도 바로 열리고 로그가 부드럽게 스크롤됩니다

## 1.0.0

### 새 기능
- 첫 릴리스: **Poweramp용 Discord Rich Presence** – Poweramp 정식 빌드와 베타 빌드 모두 지원
- 진행 표시줄이 있는 **“Poweramp 듣는 중”**(또는 경과 시간이 있는 “하는 중”)
- **스트리밍 서비스 없이도 커버 표시**: Poweramp에 표시되는 커버를 x0.at, catbox.moe 또는 Imgur에 업로드하고,
  선택적으로 온라인 검색도 사용할 수 있습니다(Spotify, Deezer, Apple Music / iTunes, Bandcamp, Discogs,
  MusicBrainz + Cover Art Archive)
- 플레이스홀더(`%title%`, `%artist%`, `%album%`, `%bar%` …)를 사용하는 텍스트 템플릿과 Discord에 표시될 내용의
  실시간 미리보기
- 일시정지 동작(“일시정지됨” 표시 또는 숨기기, 일시정지 후 제거)과 스트림 및 폴더 필터
- 업데이트 확인(GitHub 릴리스)
- 영어, 독일어, 러시아어, 우크라이나어
