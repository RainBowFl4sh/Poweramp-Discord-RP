# 更新日志

## 1.2.0

### 新增
- **关联你的 Discord 账号**（*状态* 标签页）：在实时预览和 *状态* 标签页中显示你的真实名称和头像，
  只保存公开的个人资料
- **新增 26 种语言**：法语、西班牙语、葡萄牙语（巴西）、意大利语、荷兰语、丹麦语、瑞典语、挪威语、芬兰语、
  波兰语、捷克语、匈牙利语、罗马尼亚语、希腊语、土耳其语、塞尔维亚语、阿拉伯语、印地语、印度尼西亚语、越南语、泰语、中文、
  日语和韩语（AI 翻译，欢迎指正）
- *应用设置* 中新增 **语言选择**（在 Android 13+ 上也可在 Android 的应用设置中选择）

### 改进
- 更省电：手机休眠时“已暂停”也会按时消失；状态关闭或未安装 Discord 时不再唤醒设备；
  重新连接会逐步延长间隔
- 更省流量和内存：封面重新检查的频率更低，未知专辑 12 小时内不再重复查找，
  应用在后台时会释放图片
- 修复：导入的设置会被自动纠正；从任务管理器停止后，重新播放会恢复状态显示

## 1.1.0

### 新增
- 三点菜单中的 **应用设置**：*跟随系统* / *浅色* / *深色* 主题、深色模式下的 **AMOLED 纯黑** 以及
  **Material You** 配色（Android 12+）
- **关于**：作者的 GitHub 头像和居中显示的链接
- **轮换文字**：`%artist% || %title%` 会轮流显示艺术家和标题（*显示* 标签页中的 *轮换间隔*，
  5–60 秒）
- **全新应用图标**，采用 Poweramp 的风格：带均衡器条的对话气泡（也提供 Android 13+ 主题
  图标）；应用内图标、启动画面和 Discord 图片也随之更新

### 更流畅
- 优化构建（R8 + 基准配置文件）：界面和标签页切换不再卡顿
- 设置、Poweramp 的状态和图片均在后台加载
- 实时预览每秒只更新一次播放位置；较远的标签页可立即打开；日志滚动更流畅

## 1.0.0

### 新增
- 首次发布：**Poweramp 的 Discord Rich Presence**，支持 Poweramp 的正式版和测试版
- **“正在收听 Poweramp”** 并显示进度条（或“正在玩”并显示已进行时间）
- **无需流媒体服务的封面**：Poweramp 显示的封面会上传到 x0.at、catbox.moe 或 Imgur，
  还可选择在线查找（Spotify、Deezer、Apple Music / iTunes、Bandcamp、Discogs、
  MusicBrainz + Cover Art Archive）
- 带占位符的文字模板（`%title%`、`%artist%`、`%album%`、`%bar%` …）以及
  Discord 显示内容的实时预览
- 暂停行为（显示“已暂停”或隐藏，暂停一段时间后移除）以及针对流媒体和文件夹的过滤器
- 更新检查（GitHub releases）
- 英语、德语、俄语和乌克兰语
