# Список змін

## 1.1.0

### Нове
- **Налаштування застосунку** в меню з трьома крапками: тема *Як у системі* / *Світла* / *Темна*, **чорне тло (AMOLED)**
  для темної теми та кольори **Material You** (Android 12+)
- **Про застосунок**: фото автора з GitHub і посилання по центру
- **Чергування текстів**: `%artist% || %title%` показує виконавця й назву треку по черзі (*Інтервал зміни* на вкладці
  *Вигляд*, 5–60 с)
- **Новий значок застосунку** у стилі значка Poweramp: хмаринка діалогу зі смужками еквалайзера (також тематичний
  значок Android 13+); логотип у застосунку, заставка під час запуску й зображення для Discord — у тому ж стилі

### Плавніше
- Оптимізовані збірки (R8 + baseline-профіль): сторінки та перемикання вкладок більше не гальмують
- Налаштування, стан Poweramp і зображення завантажуються у фоні
- Живий попередній перегляд щосекунди оновлює лише позицію відтворення; далекі вкладки відкриваються одразу; журнал
  прокручується плавно

## 1.0.0

### Нове
- Перша версія: **Discord Rich Presence для Poweramp** — працює зі стабільними та бета-збірками Poweramp
- **«Слухає Poweramp»** зі смугою прогресу (або «Грає» з часом, що минув)
- **Обкладинки без стримінгових сервісів**: обкладинка, яку показує Poweramp, завантажується на x0.at,
  catbox.moe або Imgur; додатково — пошук в інтернеті (Spotify, Deezer, Apple Music / iTunes, Bandcamp,
  Discogs, MusicBrainz + Cover Art Archive)
- Шаблони тексту з підстановками (`%title%`, `%artist%`, `%album%`, `%bar%` …) і попередній перегляд того,
  що покаже Discord
- Поведінка під час паузи (показувати «Пауза» або приховувати, прибирати після паузи) і фільтри для потоків
  і тек
- Перевірка оновлень (релізи на GitHub)
- Англійська, німецька, російська й українська мови
