# Setting up the Discord application

**Deutsch:** [discord-application.de.md](discord-application.de.md) · Back to the [README](../README.md)

Every Rich Presence belongs to a *Discord application*. It decides two things:

- the **name** Discord shows - "Listening to **Poweramp**" on your profile is the application's name, not a text
  the app sends (the member list shows the artist instead, unless the app's *Display* tab says otherwise)
- the **images** the presence can use by name: the logo and the play / pause icon

**Only whoever builds or publishes the APK needs this, and only once.** The application ID is compiled into the
APK, so end users install the app and are done. Users who want a different name or other images can enter their
own application on the app's *Advanced* tab - the steps are the same.

Nothing else is needed from Discord: no bot, no OAuth2, no client secret, no token. The Application ID is public
information (Discord shows it to anyone who looks at the presence), so it is fine in `gradle.properties`.

## 1. Create the application

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and log in with your Discord
   account
2. Click **New Application** (top right)
3. Name: **Poweramp** - this is exactly the text after "Listening to" on your profile. Accept the Developer Terms of
   Service and click **Create**
4. Optional, on *General Information*: upload `docs/assets/poweramp.png` as *App Icon* and add a description. Users
   do not see either in the presence itself

## 2. Copy the Application ID

On *General Information*, click **Copy** under **Application ID**. It is a number with 17 to 20 digits, e.g.
`1234567890123456789`.

## 3. Upload the art assets

The app refers to three images by name. In the left menu open **Rich Presence -> Art Assets**, click
**Add Image(s)** and upload the files from [`docs/assets/`](assets):

| Name (exactly) | File | Size | Used for |
|---|---|---|---|
| `poweramp` | <img src="assets/poweramp.png" width="64" alt="poweramp"> `poweramp.png` | 512x512 | large image when no cover is found (and while the cover is still being looked up); the test presence |
| `play` | <img src="assets/play.png" width="64" alt="play"> `play.png` | 512x512 | small icon on the cover while playing |
| `pause` | <img src="assets/pause.png" width="64" alt="pause"> `pause.png` | 512x512 | small icon on the cover while paused (*Show "Paused"*) |

- The portal takes the name from the file name. Check that the names are exactly `poweramp`, `play` and `pause`
  (lower case) before you click **Save Changes**
- Images must be at least 512x512 pixels; PNG with transparency is fine
- New or changed assets can take a few minutes (sometimes longer) until Discord shows them - Discord caches them.
  Until then the presence may show an empty square instead of the logo
- Leave *Rich Presence Invite Image* empty - it is not used

**About the images:** all three are original drawings made for this project in the style of Poweramp's round icon:
a dark disc with a light blue rim and glow on a transparent background, with a white play triangle, white pause
bars or - in `poweramp.png` - the app's own logo, the speech bubble with equalizer bars of its launcher icon. That
logo is **not** Poweramp's logo, which is a trademark of its owner. If you have permission to use the real Poweramp
icon, you can upload it under the name `poweramp` instead; nothing else has to change. The images are generated by
[`docs/assets/make_assets.py`](assets/make_assets.py) (Python 3, standard library only):
`python3 docs/assets/make_assets.py` writes them again, e.g. after changing a color.

## 4. Optional: enable the Social SDK

The Discord app's Rich Presence service belongs to Discord's **Social SDK**. If the presence does not appear
although everything else is right, enable the Social SDK for the application: in the left menu open
**Discord Social SDK -> Getting Started** and fill in the short form. Whether this is necessary is **not
confirmed** - it is a step to try, not a requirement.

## 5. Put the ID into the build

Use one of these:

- **`gradle.properties`** in the project folder:

  ```
  discordApplicationId=1234567890123456789
  ```

- **Command line** (overrides `gradle.properties`):

  ```
  ./gradlew :app:assembleRelease -PdiscordApplicationId=1234567890123456789
  ```

- **GitHub Actions**: repository *Settings -> Secrets and variables -> Actions -> New repository secret*, name
  `DISCORD_APPLICATION_ID`, value = the ID. The workflow passes it to Gradle (see
  [Publishing a release](../README.md#publishing-a-release)). A value that is not 17 to 20 digits fails the build;
  a release (`v*` tag) without any ID fails as well, other builds only warn

Without an ID the app still builds (except for a release on GitHub Actions); its *Status* tab then says that no
application ID is configured, and users have to enter their own on the *Advanced* tab.

## 6. Check it

1. Install the APK, open the app, and go through the setup on the *Status* tab (see the
   [README](../README.md#install-and-setup))
2. *Status -> Send test presence*: for 15 seconds Discord shows a test presence of **Poweramp** ("Test - Poweramp
   Discord Rich Presence ...") with the logo
3. Play a song in Poweramp: the cover appears (or the logo) with the play icon in its corner

If the name is right but the images are missing, the asset names do not match or Discord has not picked them up
yet (see step 3). If nothing appears at all, see [Troubleshooting](../README.md#troubleshooting).

## Using your own application in the app (users)

1. Create an application as above - with any name you like ("Music", "Poweramp", ...) - and upload the three
   assets `poweramp`, `play` and `pause`
2. In the app: *Advanced -> own Discord application*, switch it on and paste the Application ID
3. The app reconnects with the new ID; *Send test presence* on the *Status* tab shows the result
